## 常见问题

**韩国VPS延迟大概多少？**
走直连线路时，公开测评里82ms左右的平均值是常见水平，比美西低一大截，略高于香港和日本节点。移动用户如果路由绕行，实际数值会高一些，以自己实测为准。
